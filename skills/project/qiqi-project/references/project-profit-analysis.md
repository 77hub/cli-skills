# 项目利润分析

## 最少校准

先确认项目范围、截止日期或期间、收入和成本采用的业务阶段、含税或未税、币种与汇率口径。用户已明确的项不重复询问；任何一项会实质改变结论且无法从权威产品口径取得时，先请求确认。

## 权威事实

分别识别合同额、收入确认、开票、收款、成本发生和付款等事实。它们属于不同业务阶段，不能相互替代。只有产品已经提供权威利润口径时直接采用；否则不擅自把可见收入减去可见支出称为“项目利润”。

需要的关系包括项目归属、业务期间、组织、币种和税额口径。关系必须来自记录或元数据，不以名称相同推断归属。

## 查询与停止条件

1. 先判断业务阶段和事实边界。
2. 用 Project 确认唯一项目、期间和领域口径。
3. 用 qiqi 发现当前对象、字段和值，并用 `find list` 查询各阶段事实。
4. 对每个对象处理完整分页和大输出，记录不可见、无法关联或字段缺失的范围。
5. 只有集合完整且口径可比较时才使用产品指标或用户确认的公式计算；否则停止给出完整利润数字。

权限不可见、关系缺失、分页不完整、跨币种无汇率或口径未确认都会限制结论。把这些限制列为数据缺口，不归零处理。

## 结果结构

- 项目、期间和口径。
- 各业务阶段的原始事实及来源范围。
- 产品权威指标；没有权威口径时只给出经用户确认的推导，并明确公式和假设。
- 未知、无权或不完整项。
- 需要业务人员确认的判断。

避免把合同额当收入、把收付款当收入成本确认、混用含税和未税金额、忽略币种，或用“未查到”证明金额为零。
