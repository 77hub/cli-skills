# 项目预算执行分析

## 最少校准

先确认项目、预算版本、预算维度、期间，以及“执行”指占用、申请、承诺、发生还是付款。必要时同时确认组织、币种和含税口径。

## 权威事实

预算、占用、申请、承诺、发生和付款是不同阶段。预算执行率与剩余额度只使用产品已有权威口径；没有权威口径时先分别展示各阶段事实，不自行选择其中一个作为执行额。

分母为零、预算缺失或维度无法对齐时，不强算百分比。预算版本和业务事实期间必须可比较，调整前后版本不能静默合并。

## 查询与完整性

1. 先区分预算与执行阶段。
2. 用 Project 固定项目、预算版本和领域口径。
3. 用 qiqi 发现预算及执行对象、字段和值，再用 `find list` 查询各阶段事实。
4. 对每个对象处理完整分页和大输出，确认项目关系、期间、状态、币种和维度映射。
5. 无法取得完整集合、产品权威指标或可比较维度时，报告缺口，不生成伪完整执行率。

权限不可见、项目关系缺失、多币种无换算、状态未确认和期间不一致都必须进入限制说明。

## 结果结构

- 项目、预算版本、维度、期间与执行阶段。
- 预算、执行和差异的权威数值。
- 执行率或剩余额度及其产品口径；无法计算时说明原因。
- 数据完整性和权限限制。
- 超预算、临界项或需要人工确认的异常。

避免把付款替代成本发生、把申请替代承诺、混合预算版本，或在预算缺失时把剩余额度写成零。
