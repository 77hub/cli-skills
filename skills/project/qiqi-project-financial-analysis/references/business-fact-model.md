# 项目经营分析业务事实模型

## 财务事实域地图

| 事实域 | 标准能力候选 | 能证明什么 | 不能直接证明什么 |
| --- | --- | --- | --- |
| 项目范围 | `Project` | 项目身份、责任与周期范围 | 所有业务事实都已完整归集 |
| 项目预算 | `BudgetPlan`、`BudgetPlanTotalView`、`BudgetExeAnalysisView`、`BudgetTransactionView` | 预算基线、占用、实际执行、总消耗及来源事务 | 企业一定使用预算；会计利润或现金结果 |
| 客户承诺 | `ArContract` + `ArContractSubjectMatterItem` | 已生效客户合同的项目标的约定 | 已履约、已确认收入、已开票或已收款 |
| 供应承诺 | `ApContract` + `ApContractSubjectMatterItem` | 已生效供应合同的项目标的约定 | 成本已经发生、已取得发票或已付款 |
| 收入与应收 | `RevenueConfirmationItem`、`ArReceiptItem` 及其主单 | 已生效主单下的项目收入确认或其它应收明细 | 已开票或已收到现金 |
| 开票 | `InvoiceItem`、`PurchaseInvoiceItem` 及其主单 | 已生效主单下的销售或采购发票明细 | 收入成本已按企业口径确认；现金已收付 |
| 应付与费用成本 | `ApPaymentItem`、`ReimburseItem` 及其主单 | 已生效主单下的项目应付、费用等资源消耗明细 | 已付款；全部都可计入项目利润 |
| 人力投入 | `TimesheetLine` + `Timesheet` | 已生效工时单下的项目工时；有成本字段时提供工时成本事实 | 没有可验证工价时的人工成本 |
| 资金 | `ReceiptItem`、`PaymentItem` 及其主单 | 已生效主单下的项目收付款和核销明细 | 利润、收入或成本 |
| 企业扩展 | 自定义对象、字段、视图和报表 | 企业自己的财务事实与指标 | 定义天然完整或无需核验 |

这些对象是标准产品候选，不是企业必须采用的固定流程。运行时未发现时继续按中文业务词搜索，仍未确认时报告能力未知。

## 主单、明细与项目归属

经营分析默认以单据明细作为项目归集粒度，并以父单控制业务状态：

```text
项目归属与金额：明细行
BillStatus.effective：父单
业务日期和组织：按元数据确认来自父单或明细
```

同一主单的明细分属多个项目时，系统可能清空表头项目。只按主表 `projectId` 查询会漏掉这类事实。只有元数据证明没有项目明细，或该对象的项目只能位于主表时，才能直接使用主表项目。

明细行不拥有独立的完整单据生命周期。默认通过真实父单关联筛选 `BillStatus.effective`；用户明确要求其它状态时才扩大范围，并披露具体状态。

同一链条的不同阶段不能直接相加。例如收入确认、销售发票和收款用于观察转换与差异，不是互斥收入桶；应付、采购发票和付款同理。

## 收入侧事实链

```text
客户承诺 -> 履约或交付 -> 收入确认或应收 -> 开票 -> 收款与核销
```

合同累计字段可能与来源单据表达同一事实。除非明确采用合同累计口径，不把合同累计字段与执行单据再次相加。

## 成本费用侧事实链

```text
采购或费用申请 -> 合同或订单承诺 -> 到货或资源消耗 -> 应付或报销 -> 采购发票 -> 付款与核销
```

- 未来压力可观察申请、订单、合同和项目预算占用；
- 已发生投入可观察采购入库、材料发出、报销分摊、工时成本或企业确认的成本事实；
- 负债和票据可观察应付及采购发票；
- 现金流出只观察已付款事实。

待分摊费用不自动归属于当前项目；只有分摊关系或明确项目字段能证明归属时才计入。

## 人力事实

`TimesheetLine.hours` 是明细工时事实，`TimesheetLine.workCost` 是系统在相应配置下形成的明细工时成本候选；父 `Timesheet` 用于确认单据状态。没有可见成本字段、工价或企业确认依据时，只报告工时，不自行假设时薪补算成本。

## 下行风险

- 把现金净流入命名为利润，会忽略应计收入、未付成本、税额、期初和跨期事实。
- 把合同总额减付款命名为毛利，会混合承诺与资金阶段。
- 同时累计汇总报表和来源单据，会重复计算。
- 只按表头项目查询，会漏掉同一主单内分属多个项目的明细。
- 忽略红冲、冲销、变更版本和未生效状态，可能反转结论。
- 把标准模型当作企业强制流程，会遗漏自定义对象或企业权威口径。
