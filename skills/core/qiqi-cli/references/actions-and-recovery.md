# 记录动作与未知结果核查

## 执行记录动作

提交、撤回、审批等动作按记录逐条实时发现：

1. 用稳定 `RecordRef` 确定目标；需要核对状态等事实时，用 `records get` 读取所需字段。
2. 用 `describe actions <RecordRef>` 取得此刻允许的动作和参数。不同记录、用户或企业可能得到不同的动作，不复用其它记录的结果。
3. 核对动作与用户意图一致后，用 `do-action` 执行一次，再根据返回或回读确认结果。
4. 收到 `BUSINESS_WARNING` 时，向用户展示警告明细；用户明确确认后，才加 `--ignore-warn` 再执行一次。

参数写法以 `do-action --help` 和 `describe actions` 的返回为准。

## 删除

删除不可逆。先执行预检查，向用户展示目标和影响；用户明确授权后才加 `--yes`。只有返回明确表示成功时，才报告已删除。

## 未知结果核查

超时、断连或响应不完整时，CLI 无法判断写入是否生效。此时标记“状态未知”，不重放请求，按已知信息核查：

- 有 `RecordRef`：读取该记录的状态和关键字段。
- 有唯一业务编码：按编码精确查询。
- 只知道待办列表有变化：重新读取对应视图，但列表变化本身不能证明动作成功。
- 新建类操作：按本次业务事实和时间范围查找候选。

核查只能说明记录当前的样子。仍无法确认时，把候选和未知状态告诉用户，由用户决定下一步。
