# 审批与附件

## 审批

1. 从待办视图（如「待我审批」）或用户指定的单据取得 `RecordRef`。
2. 每张单据都用 `describe actions <RecordRef>` 取得当前可用的动作，如同意、驳回。动作 ID 和参数不能沿用其它单据的。
3. 核对单据、动作、审批意见和影响后，用 `do-action` 执行，见 [记录动作](actions-and-recovery.md)。

批量审批时，可以沿用用户对同一范围和同一意见的授权，但每张单据仍逐张发现动作。

## 附件

附件挂在已保存的记录或明细上：

1. 新建记录先保存并取得 `RecordRef`，再上传附件；预览中的记录不能挂附件。
2. 查看或下载文件时，用 `records attachments url` 取得临时链接，不自行拼接文件地址。
3. 上传和删除都是写操作，参数和确认要求以命令 `--help` 为准。

附件上传失败或结果未知时，用 `records attachments list` 查看该记录的现有附件，不重复上传，也不重建业务记录。返回 `ATTACHMENT_OUTPUT_FAILED` 或 `write_saved` 表示附件已经挂上，只需重新读取附件列表。

`invoice upload` 用于把发票识别后放入发票池，和挂载附件是两回事；它不需要先保存报销单。
